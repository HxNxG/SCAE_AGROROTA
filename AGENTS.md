# Instrucciones para agentes

- Lee [REGLAS.md](REGLAS.md) antes de trabajar con datos y la [guía de AgroRota](proyecto-agricultura-ia/docs/GUIA_AGENTES.md) antes de modificar la aplicación.
- Usa el inventario y los README de cada fuente para localizar insumos. Comprueba la disponibilidad efectiva, cobertura, licencia y versión antes de usar un producto.
- Mantén los datos originales y sus metadatos. Guarda transformaciones reproducibles y anota su origen, parámetros y cobertura. Respeta los trabajos de extracción ya asignados.
- Comprueba el estado de Git y revisa el diff antes de publicar. Incluye solo archivos de la tarea. Mantén fuera de Git credenciales, configuraciones privadas, datos personales y archivos pesados.
- Verifica el cambio desde su punto de entrada habitual y registra qué comprobaste, qué datos usaste y qué queda pendiente.
