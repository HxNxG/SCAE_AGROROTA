# Información agropecuaria ecuatoriana

Se incorporaron los [tabulados provinciales de la ESPAC 2025](ESPAC_INEC/README.md) para las siete provincias, con superficie, producción, ventas, uso del suelo, riego y labranza.

Priorizar para la Costa: superficie sembrada y cosechada, rendimientos, calendarios agrícolas, variedades, riego, manejo de suelos, rotaciones y asociaciones documentadas. Verificar disponibilidad, escala y comparabilidad por año y territorio.

Crear una carpeta por base identificada, con institución, enlace oficial, producto, licencia, variables, cobertura, metodología y brechas. Aplicar las [reglas](../REGLAS.md) y actualizar el [estado regional](../09_cobertura_y_brechas/ESTADO_POR_REGION.md).
